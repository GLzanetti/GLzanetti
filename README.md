## 🚀 Projetos em destaque

### 🏋️ [Overload](https://github.com/GLzanetti/Overload) · *em desenvolvimento*
Plataforma de acompanhamento de treinos de academia, construída em **microsserviços Java**.
- **Gateway** com validação central de JWT e `usuario-service` (cadastro, login e emissão de token) prontos; `treinos-service` em desenvolvimento
- A identidade do usuário vem do token, nunca do corpo da requisição; senhas com BCrypt
- Próximos passos: métricas com MongoDB, Docker, deploy na AWS e testes automatizados
- `Java 21` `Spring Boot 4` `Spring Security` `JWT` `PostgreSQL` `Swagger`

### 🎙️ [Budgeting](https://github.com/GLzanetti/ProjetoBudgetingItauEDio)
Assistente financeiro por voz com LLM, projeto final do bootcamp DIO com Itaú.
- Você fala, o **Gemini** transcreve, um agente com **Tool Calling** registra, lista e soma os gastos, e a resposta volta em áudio
- Arquitetura **hexagonal com DDD**: o Gemini fica isolado em um adaptador
- **32 testes unitários** (JUnit 5, Mockito, JaCoCo) e MySQL em Docker Compose
- `Java 21` `Spring Boot 4` `Spring AI` `MySQL` `Docker Compose`

### 🧠 [README-IA](https://github.com/GLzanetti/README-IA)
Sistema multiagente que lê um repositório e gera o README em cerca de 30 segundos.
- 3 agentes (Explorador, Analista, Escritor) definidos **só em Markdown**, portáveis entre IDEs
- Gerou o README do Budgeting
